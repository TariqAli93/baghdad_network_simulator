# Building-height fieldwork — Tahrir Square / Bab Al-Sharqi

Files in this folder:

| File | Use |
|---|---|
| `fieldwork_map.pdf` (A3) / `.png` | where the buildings are; the number on each building is its `map_no` |
| `observation_priorities.csv` | every building, its priority, **why** it is listed, its current height and source, coordinates (lat/lon) and an OpenStreetMap link where one exists |
| `observation_template.csv` | **the file you fill in**, one row per building, already in priority order |

Generated by `scripts/fieldwork_package.py` from `height_worklist.csv`. Nothing in these
files is an observation yet: every height there is OpenStreetMap, an estimate from storeys, or
the 9 m placeholder.

### Two stages

Acceptance is checked per group (configs/study_area.yaml, `method_requirements`): P0-P2 need a
`measured` or `documented` row (38 buildings); S needs a `storey_count` row with `storeys`
(43). A visual estimate completes neither; a storey count is recorded as *estimated*, never as
a measured height. The Study area and Overview pages show the two groups' progress separately.

1. **Stage 1:** P0, P1 and P2 (measured or documented), and the S buildings (storey counts).
   Import them (below) and regenerate the worklist: new candidate roofs appear, and with them
   new P2/P3 buildings that may need observing (report them to the supervisor).
   The command below uses the provisional **evaluation** thresholds (roof ≥ 12 m, 50 m spacing,
   up to 40 sites; the 100 m² minimum area is not an option of this tool), not approved values.
   ```
   uv run python scripts/height_worklist.py --area tahrir_bab_al_sharqi_study --add-footprints 3d_globfp --observations <stage1.csv> --mast-height-m 3 --min-site-height-m 12 --site-spacing-m 50 --max-sites 40 --tall-m 20 --near-site-m 150 --blocking-share 0.5
   uv run python scripts/fieldwork_package.py --area tahrir_bab_al_sharqi_study --variant osm+fp_3d_globfp
   ```
   The supervisor then sets the A4 minimum roof height, area and spacing (20-40 candidates).
2. **Stage 2:** the regenerated P2 and P3 list.

## How to observe (`method_class`)

| method_class | What it means | Recorded as | Typical uncertainty |
|---|---|---|---|
| `measured` | laser rangefinder or clinometer from the street: height = horizontal distance × tan(angle to the roof edge) + your eye height; or a rangefinder's height mode | **observed** | ±1 m (rangefinder), ±2 m (clinometer) |
| `documented` | a reliable written record of that building's height (permit, municipal record, architect's drawing, a published survey); put the reference in `source` | **observed** | as stated by the source |
| `storey_count` | storeys counted from the street; leave `height_m` empty, the software uses the approved 3.0 m per storey | **estimated**, never "measured" | about ±0.5 m per storey |
| `visual_estimate` | judged against a nearby building of known height | **estimated** | state it (often ±3 m or more) |

Fill in `date` (YYYY-MM-DD), `observer`, `uncertainty_m`, and `notes` (roof structures,
parapets, setbacks, doubts). Measure to the **main roof**, not to antennas or water tanks;
note those separately. Leave a row empty if you could not observe the building — **never fill
in a guess as a measurement**.

## Safety and permissions

- Observe only from public streets and squares. Do not enter rooftops, private property,
  construction sites or restricted areas, and do not ask to be let in for this purpose.
- Several buildings near Tahrir Square may be government or security buildings: do not
  photograph or measure where it is not allowed; skip them and say so in `notes`.
- Watch traffic when aiming instruments; work in daylight, preferably with a second person.

## Import

Save the filled template (keep the first `#` line; it is ignored), then:

```
uv run python scripts/build_dataset.py --area tahrir_bab_al_sharqi_study --add-footprints 3d_globfp --observations <filled_template.csv>
```

- Invalid rows (negative or implausible heights, fractional storeys, unknown method class,
  negative uncertainty) stop the import and are listed; fix them and run again.
- Every observation file gives a new dataset version `osm+observations-<8 characters of its
  SHA-256>+fp_3d_globfp`, with `dataset_manifest.json` recording the checksums.
- The quality report says whether the dataset is fit for research. It becomes fit only when
  **every required building** of `observation_priorities.csv` has a valid observation; the
  report lists how many are still missing.
